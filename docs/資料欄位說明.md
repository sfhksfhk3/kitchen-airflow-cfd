# OpenFOAM 廚房比較交付資料

請先閱讀 `openfoam_oil_analysis_zh.pdf`。互動圖為
`kitchen_oil_openfoam_interactive_3d.html`，下載後以桌面瀏覽器開啟；已內嵌程式及抽樣資料，不需要連網。電腦需支援 WebGL。

`figures_1to1/` 含每幅正方形 PNG、PDF 和 SVG；兩位置的比較合併於同一幅圖。兩種位置的全室／走道衰減合併成四格圖。`all_figures_1to1.pdf` 為合訂圖集。

## 數據

- `mixture_summary_reference_scenario.csv`：八工況的參考油滴質量情境比較。
- `independent_size_summary.csv`：八工況 × 五個獨立粒徑的單位排放響應。
- `numerical_sensitivity.csv`：後段時間步／網格敏感性，並非完整歷程網格收斂證明。
- `data/案例名/history_all_sizes.csv`：逐時刻、逐粒徑的原始質量收支及熱流診斷。
- `data/案例名/mixture_history_reference_scenario.csv`：參考分布混合後的濃度、存量與去向。
- `data/案例名/emission_distribution_sensitivity.csv`：GSD=1.2、1.5、2.0 × 排放量0.25、1、4倍的線性重組。
- `cells_*s.csv` 與 `fields_*s.vtu`：完整單元中心數據及三維場。檔名標示實際保存時刻；VTU 可直接用 ParaView 開啟。
- `visualization_frames.npz`：互動圖各保存時刻的全單元數據；內嵌HTML只抽樣顯示。

案例前綴 `corner` 為靠左，`center` 為置中；門況 `both_open` 兩門全開、`both_closed` 兩門全關、`left_open` 左開右關、`right_open` 右開左關。

## 單位和解讀

五個粒徑0.1、0.3、1、3、10µm分別以兩爐合計1µg/s獨立計算，沒有假定每種占20%。`C/R` 的單位為 s/m³；乘上該粒徑實際排放率（µg/s）得到 µg/m³。

參考混合情境採兩爐共14.4mg/min（240µg/s）、質量中位徑2.5µm及假設GSD1.5。這是文獻轉用的油滴總質量情境，不是住家實測、PM2.5或完整超細粒子數分布。CSV內 `_kg` 為公斤、`_mg` 為毫克、`_ug_m3` 為微克／立方米、`_s` 為秒、比例欄位0–1。

時間是模擬物理時間；0–120s放熱及排放，120s後兩者停止，排風持續到240s。起始25°C不表示曾計算材料從25°C升溫至穩態；本模型沒有板材導熱、熱容量或鍋具餘熱。

走道指廚房內 y>0.6m、z=0.9–1.8m，沒有計算門外住宅。煙機排出量指經吸口離開計算域，不是濾網效率；沉積量為留在表面的油滴，不等於已被清潔。

原生案例及求解器來源另見 `openfoam_cases_sources.zip`，解壓後依 `README_zh.md` 重現或續算。壓縮檔內附 SHA-256 清單；壓縮檔自身雜湊見 `archive_verification.json`。
