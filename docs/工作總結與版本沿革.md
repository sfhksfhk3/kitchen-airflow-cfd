# 工作總結與版本沿革

## 問題與幾何

目標是比較左右兩道門開關時的油煙滯留，再比較灶台／煙機靠左與移到可用檯面中央。房間3.3×1.65×2.2m；兩門90×220cm，關門底縫各5mm。煙機90×30cm，離灶面70cm，前緣10cm擋板向下45°且僅覆蓋煙機寬度。靠左的左爐距高櫃右側25cm；兩爐均在y=0.3m。

## 為甚麼舊溫度不能直接當作櫃板溫度

早期空氣模型只有簡化對流散熱邊界，沒有材料導熱、熱容量或火焰／鍋具直接輻射。空氣或邊界的穩態溫度不包含「由25°C加熱多久」的答案。後來的一維固體計算只是給定迎熱空氣與膜係數後，估算材料的暫態反應；其95%時間指95%最終溫升，不是實際廚房由開火起的達穩時間。

## 示蹤物與油滴的差別

被動示蹤物主要隨氣流輸送與擴散。已形成的油滴還會受粒徑影響而沉降、熱泳、沉積。炒菜熱羽流需要熱量—密度—氣流耦合；但稀薄油滴的質量負載很小，並不必然需要強顆粒動量回饋。本版是五個獨立Eulerian漂移／擴散響應，並非完整油煙化學或相變模型。

## 如何理解平均滯留短但走道濃度高

大部分油滴很快被煙機帶走時，全室平均滯留可以很短；少量油滴只要偏向走道，就能提高局部濃度。關火後先快後慢、曲線互相超越，也可能來自源區快速清除與回流／死角慢速尾巴的不同占比。應同時讀取絕對濃度、全室存量和各自歸一化衰減，不能只看起始斜率。

## 新舊版本不能直接混比

初版1200W、短暫9000W、後來4000W的條件不同。舊示蹤衰減使用固定熱流場，最新OpenFOAM在120s同時停止放熱和排放、風機繼續運轉到240s；差值不能全歸因於更換求解器。所有階段均保留自己的設定、報告和限制。

## 最新結果應如何使用

主README與最新PDF列出八工況數字。雙關門在本組補風／風量假設下較容易滯留；搬動灶台的優劣仍須連同門況、局部濃度的絕對量，以及數值／源強不確定性判斷。尚無足夠依據用這些數字保證實際捕煙率、建議精確延時關機秒數，或判定板材耐熱安全。
