# 廚房 OpenFOAM 油滴／熱浮力計算

本目錄沿用使用者已確認的廚房尺寸，將計算轉為 OpenCFD OpenFOAM 2406 有限體積法。舊有限元成果保留在 `/workspace/kitchen_compare`。`PROGRESS.json` 和 `batch_status.json` 記錄可續算狀態。

## 模型

- 房間3.3×1.65×2.2m；高櫃x=0–0.7m；檯面高0.9m、深0.6m；頂吸煙機90×30cm，離檯面70cm。
- 靠左整體中心x=1.15m；置中x=2.0m；爐頭間距40cm，y=0.3m。擋板長10cm向下45°，只覆蓋煙機90cm寬度；採零厚度無穿透面。
- 兩道門90×220cm，位置沿用草圖y=0.7–1.6m。四種門況各兩種位置。關門的5mm門縫採實際幾何開口，基準網格沿高度兩個單元。
- 兩爐各向空氣放熱2000W。以歸一化高斯體積熱源表示；沒有火焰／鍋具幾何、人體、燃氣反應、水蒸氣或直接輻射。
- 理想氣體密度ρ(p,T)、Sutherland黏度、瞬態PIMPLE、k–ω SST與浮力湍流源。牆面對25°C環境的簡化散熱係數3W/(m²K)；這不是顆粒板／不鏽鋼共軛傳熱模型。
- 煙機採均勻縮減負壓，局部速度自由求解。回授壓力使體積流量接近既有二次風機／孔口網路假設的工作點：開門約0.5m³/s，雙關約0.226m³/s。這些不是實測運轉風量。沒有煙管及濾網模型，不能把控制負壓當作完整風機靜壓預測。
- 門口採環境縮減總壓，無外部穿堂風；入口靜溫25°C，未作高速門縫的入口總溫修正，量級約0.3°C。入口湍流k=0.001m²/s²、ω=1s⁻¹為未校準近似；SST在室內計算變動渦黏性。
- 油滴為稀薄、已形成的球形顆粒。分開求解0.1、0.3、1、3、10µm五個獨立單粒徑響應，每個參考排放率為兩爐合計1µg/s。它們不是五等分的實際油煙。
- 包含Stokes–Cunningham重力沉降、Stokes–Einstein布朗擴散、Talbot熱泳、Sc_t=0.7湍流擴散，以及近壁擴散阻力與向壁漂移形成的黏附沉積通量。密度850kg/m³、導熱0.17W/(m·K)、黏附率1。
- 沒有蒸發、凝結、成核、凝併、再懸浮、油膜或慣性撞擊；未涵蓋全部<0.1µm超細粒子，也未求解VOC。粒子不回饋氣流；此處稀薄油滴的質量負載很小，而溫度、密度與氣流維持耦合。
- 初始25°C；放熱與排放持續120秒，然後兩者停止，排風至240秒。這是理想化兩分鐘烹調段，沒有熄火後鍋具／板材餘熱。

文獻來源與採用方式見 `references/SOURCES_zh.md`。參考質量情境在 `emission_scenario.json`；文獻資料、跨場景轉用和自訂分布寬度有分別標示。

## 數值與驗證

基準使用Gmsh二維重組面網格沿x拉伸為六面體／稜柱，名義h=0.1m，熱源及擋板局部較密。實際5mm門縫高度有兩層單元。原有四面體FEM網格與被拒絕的OpenFOAM試算均保留在`verification/`，不可當作新結果。

速度與顆粒使用迎風離散，熱量使用受限線性離散；Euler時間積分。PIMPLE兩次外迭代、兩次壓力校正。開門工況maxΔt=0.05s、maxCo=3；雙關啟動階段maxCo=3，其後採maxCo=12、maxΔt=0.04s以處理近穩態高速門縫噴流。較小時間步、網格及模型敏感性必須另查驗；求解殘差與守恆不是實驗驗證。

每一時間步儲存五粒徑的排放、空氣存量、煙機排出、兩門排出與壁面沉積收支，以及氣體質量／熱量診斷。每10秒保存原生OpenFOAM場及累積狀態，可續算。穩態SIMPLE與指定點速度的診斷未被採納。

後段網格檢查從約100秒的保存狀態轉移到h=0.08m、門縫四層的網格，近地單元逐步增厚。正權重插值後逐粒徑保持總質量，再以壓力型投影校正初始面質量通量；`aerosolState`保存投影完成標記，續算不重複投影。這不是完整歷程的獨立網格收斂試驗。嚴格checkMesh對扁長近地單元仍有行列式警告，實際數量見驗證記錄。

## 執行與續算

Docker映像：`opencfd/openfoam-default:2406`；已查得映像摘要 `sha256:dd5aa20630a55722663bf83ba0cb74870cba130081303e32e3865007fa2aa35a`。目前容器為`kitchen-openfoam-2406`，將主機`/workspace`掛載至容器`/workspace`，每個工況使用單一程序；多工況可平行。自訂診斷的MPI多程序模式未驗證，應使用本專案的工況排程。

1. 在容器中進入`src/kitchenAerosolFoam`執行`wmake`。已交付完整來源與Make檔，**不要重跑舊的`prepare_solver.py`修補腳本**。
2. 新工況可用`python scripts/build_cases.py --h .1 --end 240`建模；有成功時間步的目錄應續算，不可覆蓋初始條件。
3. 執行`python scripts/run_batch.py --workers 2`。排程會讀取最新原生時間目錄，已到終止時間的工況直接跳過。`scripts/monitor_runtime.py`在雙關啟動10秒後切換時間步設定，變更另存`runtime_timestep_events.json`。
4. `stopAt writeNow`可保存當前狀態並停止；續算前改回`stopAt endTime`。狀態在時間目錄中的`aerosolState`，不可刪除再把先前累積排出量當作零。
5. 全部完成後執行`python scripts/process_results.py`匯出資料。它只讀取保存場，不會重跑CFD。

分析環境套件版本見`requirements-analysis.txt`；另需系統Chromium與Noto CJK字體。完整軟體版本在`verification/environment_versions.json`。若另建容器，必須把本專案放在`/workspace/kitchen_openfoam`或一致修改Make/files與排程的絕對路徑。資料匯出後依序執行`verify_physics.py`、`validate_results.py`、`visualize_results.py`、`make_report.py`；每次運算均保留diagnostics及原生aerosolState。

原生場是單元中心資料；`.foam`可交給ParaView。匯出CSV／VTU會標明單位、參考源強和文獻情境。`sourceShape`的體積積分為1，兩個熱源合計4000W。

## 使用結果時

空氣存量降低、排到門外、被煙機帶走，以及沉積到表面是不同去向。沉積不等於表面已清潔。文獻情境的µg/m³是條件式模型輸出，不能稱為家中實測濃度，也不能把總油滴質量直接稱作PM2.5。

本計算的迭代數與電腦運算時間都不代表物理加熱時間。新熱邊界仍不足以推算顆粒板／不鏽鋼的實際溫度或材料安全性。
